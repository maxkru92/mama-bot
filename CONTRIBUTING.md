# Contributing

1. Keine Secrets, echten Telefonnummern oder lokalen Datenbanken committen.
2. Änderungen klein und fokussiert halten.
3. Vor einem Pull Request ausführen:

```bash
npm run check
```

4. Webhook-, Deduplizierungs-, Outbox- und Sicherheitsfälle immer mit Tests abdecken.
5. Meta- und Cloudflare-Dokumentation bei API- oder Quota-Änderungen prüfen.
